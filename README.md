# Gaze Dwell Click — 시선 마우스

웹캠으로 쳐다보는 곳에 마우스 커서가 따라가고, 한 지점을 **1초간 응시하면 자동으로 좌클릭**되는 프로그램.

오픈소스 [EyeGestures](https://github.com/NativeSensors/EyeGestures)(NativeSensors, Python)를 코어로 사용한다. 별도 하드웨어 없이 노트북 웹캠만으로 동작한다.

## Windows 실행 파일 (설치 불필요)

[Releases](../../releases)에서 `gaze-dwell-click.exe`를 받아 더블클릭하면 바로 실행된다.

- 처음 실행 시 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행** 클릭(서명되지 않은 exe라 뜨는 정상 경고).
- 실행하면 검은 콘솔 창 + 캘리브레이션 화면이 뜬다. 콘솔 창을 닫으면 프로그램도 종료된다.

## 요구 사항 (소스 실행 시)

- Python 3.10 ~ 3.12
- 웹캠
- OS: Windows / macOS / Linux(X11)

> Linux는 Wayland에서 pynput 커서 제어가 안 된다. X11 세션에서 실행할 것.
> macOS는 처음 실행 시 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용** + **카메라** 권한을 터미널(또는 실행 앱)에 줘야 한다.

## 설치

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 실행

```bash
python main.py
```

1. 전체화면 캘리브레이션이 시작된다. 빨간 점 9개가 순서대로 나오는데, **점을 정확히 맞출 필요 없이** 그냥 쳐다보기만 하면 된다 — 점마다 2.5초씩 자동으로 다음으로 넘어간다(파란 원호가 카운트다운). 약 20초 걸린다.
2. 완료되면 미리보기 창이 뜨고 시선대로 커서가 움직인다.
3. 한 지점을 1초간 쳐다보면 자동으로 좌클릭. 클릭 후에는 시선을 다른 곳으로 옮겼다가 돌아와야 다음 클릭이 된다(연타 방지).

## 떨림 보정 방식

눈동자는 한 곳을 봐도 계속 미세하게 움직이고, 웹캠 추정에도 오차가 섞여서 점이 흔들린다. 그래서:

1. **1€ 필터**로 시선 좌표를 평활화한다. 한 곳을 볼 때는 강하게 떨림을 없애고, 크게 시선을 옮길 때는 바로 따라간다.
2. 응시 기준점은 첫 점이 아니라 **응시 중 모인 점들의 평균(중심)**으로 계속 보정된다.
3. 반경 밖으로 순간 튀거나 눈을 깜빡여도 **0.35초까지는 응시가 끊기지 않는다**.
4. 응시가 진행되면 커서를 **응시 중심에 고정**하고, 클릭도 그 중심에 한다.

## 키

| 키 | 동작 |
|---|---|
| q / ESC | 종료 |
| c | 재캘리브레이션 |
| s | 캘리브레이션 건너뛰기(정확도 낮음, 빠른 테스트용) |
| 스페이스 | 커서 제어 일시정지/재개 |

## 옵션

```bash
python main.py --dwell 2.0          # 응시 시간 2초로
python main.py --calib-time 4.0     # 캘리브레이션 점당 자동 진행 시간 늘리기
python main.py --radius 120         # 응시 반경 120px (기본: 화면 짧은 변의 9%, 흔들림 크면 키우기)
python main.py --smooth 0.3         # 떨림 보정 더 강하게 (기본 0.6, 작을수록 부드럽고 느림)
python main.py --grace 0.5          # 응시 중 튐/깜빡임 허용 시간 늘리기 (기본 0.35초)
python main.py --no-snap            # 응시 중 커서를 중심에 고정하지 않기
python main.py --camera 1           # 카메라 번호 지정
python main.py --list-cameras       # 열리는 카메라 번호 목록만 출력
python main.py --no-click           # 클릭 없이 시선 추적만
python main.py --video face.mp4     # 웹캠 대신 영상 파일로 테스트
```

## 팁

- 정확도가 이상하면 `c`로 재캘리브레이션. 자세/거리가 바뀌면 다시 잡는 게 좋다.
- 조명이 밝고 얼굴이 정면으로 잘 비칠수록 정확하다.
- 응시 반경(`--radius`)을 크게 하면 떨림이 있어도 클릭이 잘 되지만, 작은 버튼을 조준하기 어려워진다.

## 카메라가 안 열릴 때

프로그램이 원인을 자동으로 좁혀서 알려준다 (윈도우).

- **'카메라 액세스'가 꺼져 있음** → 설정 → 개인 정보 보호 및 보안 → 카메라 → '카메라 액세스' 켜기. 관리자 정책으로 잠겨 있으면 전산 담당자에게 요청.
- **'데스크톱 앱 허용'이 꺼져 있음** → 같은 화면 맨 아래 '데스크톱 앱이 카메라에 액세스하도록 허용' 켜기.
- **카메라 장치가 검색되지 않음** → USB 웹캠 연결, 노트북은 카메라 스위치/Fn 키 확인.
- **장치·권한은 정상** → Zoom/Teams/브라우저 등 카메라 쓰는 프로그램을 모두 닫고 재실행, `--list-cameras`로 번호 확인.

`exe`를 더블클릭했을 때 오류가 나면 같은 폴더의 `gaze-crash.log`를 이슈에 붙여주면 된다.
